# 11th Monthsary Website

A responsive, single-page anniversary website with an original instrumental soundtrack.

## Preview locally
1. Extract the ZIP.
2. Open `index.html` in a browser.
3. The music control becomes available after the page and local audio resource are ready.
4. Music starts only after the visitor taps **Play our song**, because mobile browsers restrict autoplay.

## Personalize it
- Edit the letter and the 11 reasons in `index.html`.
- Change the date text in the hero section if needed.
- Replace `assets/our-song.wav` with your preferred licensed audio file. If you use an MP3, update the `<audio src="assets/our-song.wav">` path to your MP3 filename.
- The photo upload controls let you preview photos in the browser. They do not upload or save those photos to the website.

## Publish it online for free with GitHub Pages
1. Sign in to GitHub and create a **Public** repository, for example `our-11-monthsary`.
2. Upload `index.html` and the `assets` folder (keep the folder structure).
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select **main** and **/(root)**, then save.
6. Wait for GitHub Pages to publish. Your website link will appear in the Pages section.

Keep the repository public if using GitHub Pages on a free personal account. Anyone with the link can visit the website.
